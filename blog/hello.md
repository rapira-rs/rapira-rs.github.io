# Rapira is public

This blog contains Rapira release news and technical decisions.

The documentation site and blog are now available. The blog will explain releases and design decisions.

On July 20, we made all Rapira repositories public. The [rapira-rs](https://github.com/rapira-rs) GitHub organization contains the source code.

You can use these community resources:

- **Star [the repository](https://github.com/rapira-rs/rapira)** to help other users find it.
- **Use the [issues](https://github.com/rapira-rs/rapira/issues)** to ask questions, propose features, or discuss existing proposals.
- **Join the [Discord](https://discord.gg/z7dcFATc9Q) chat** for other discussions. Use the issues to propose and discuss new functions.
- **Watch the repository** to receive project updates.
