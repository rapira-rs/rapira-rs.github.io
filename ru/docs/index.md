# Что такое Rapira

Rapira — быстрый и безопасный сервер приложений для PHP, написанный на Rust.

Мы применили многолетний опыт поддержки RoadRunner и спроектировали Rapira так, чтобы взаимодействие с PHP получилось максимально эффективным и стабильным, а разработка и эксплуатация не требовали лишних усилий.

Rapira не ограничивается только HTTP. У нас в планах поддержка всех популярных плагинов RoadRunner. Следите за обновлениями в нашем [блоге](/ru/blog/).

## HTTP

Первичная задача PHP-сервера — обслуживание HTTP-запросов. Благодаря технологиям Cloudflare, Rapira умеет принимать их напрямую, без nginx или Apache, поддерживает все современные стандарты HTTP и шифрования.

На стороне PHP поддерживаются все модели работы:

- Классический (SAPI) — каждый запрос поднимает приложение с нуля, как под php-fpm.
- Воркер (SAPI Worker) — приложение поднимается один раз при старте, а дальше обрабатывает запрос за запросом в цикле через SAPI-интерфейс (суперглобальные переменные PHP заполняются заново на каждый запрос).
- Диспетчер — приложение не умирает, а запросы и ответы передаются через отдельное API. В этом режиме вы вольны обрабатывать запросы последовательно (как в RoadRunner) или асинхронно (используя [файберы](https://www.php.net/manual/language.fibers.php)).
