# Что такое Rapira

Rapira — быстрый и безопасный сервер приложений для PHP, написанный на Rust.

Мы применили многолетний опыт поддержки RoadRunner и спроектировали Rapira так, чтобы взаимодействие с PHP получилось максимально эффективным и стабильным, а разработка и эксплуатация не требовали лишних усилий.

Rapira не ограничивается только HTTP. У нас в планах поддержка всех популярных плагинов RoadRunner. Следите за обновлениями в нашем [блоге](/ru/blog/).

## HTTP

У Rapira собственный HTTP-фронт, построенный на библиотеке [hyper](https://hyper.rs). Фронт принимает открытые HTTP-соединения напрямую, поэтому ставить перед ним что-то ещё, чтобы добраться до вашего PHP-приложения, не нужно. TLS фронт не терминирует. Нужен TLS — терминируйте его на прокси перед Rapira; как это устроено, показывает раздел [Запуск в продакшене](/ru/docs/deployment).

На стороне PHP поддерживаются все модели работы:

- Classic: каждый запрос поднимает приложение с нуля, как под php-fpm.
- Worker: приложение поднимается один раз при старте, а дальше в цикле обрабатывает запрос за запросом. Суперглобальные переменные PHP Rapira заполняет заново на каждый запрос.
- Dispatcher: приложение поднимается один раз и продолжает жить. Скрипт забирает каждый запрос вызовом API и работает с запросом как с обычным значением, а не через суперглобальные переменные. Запросы он обрабатывает по одному за раз или сразу несколько — с помощью [файберов](https://www.php.net/manual/en/language.fibers.php).
