# Стать спонсором

Rapira — открытый проект под свободной лицензией: сервер можно использовать бесплатно, в том числе в коммерческих продуктах. Разработку финансируют спонсоры, и на этой странице рассказано, как к ним присоединиться.

<script setup>
import { VPTeamMembers } from 'vitepress/theme'
import { members } from '../.vitepress/theme/team'
</script>

## Команда

Мы много лет создаём и сопровождаем открытые проекты и библиотеки корпоративного уровня: RoadRunner, Temporal PHP SDK, Spiral, Cycle, Yii3 и другие.

Самый простой способ помочь — поставить звезду [репозиторию Rapira](https://github.com/rapira-rs/rapira): чем их больше, тем проект заметнее. А финансовая поддержка идёт напрямую каждому из нас:

<div class="rapira-team">
  <VPTeamMembers size="small" :members="members" />
</div>
