# Become a Sponsor

Rapira is an open source project under a permissive license: the server is free to use, commercial products included. The work is funded by sponsors, and this page explains how to become one.

## The team

We have spent years building and maintaining open source projects and enterprise-grade libraries: RoadRunner, Temporal PHP SDK, Spiral, Cycle, Yii3 and others.

The simplest way to help is to star the [Rapira repository](https://github.com/rapira-rs/rapira): the more stars, the more visible the project. Financial support goes directly to each of us:
